## Vectorize Agent Memory Benchmark (AMB)
- **Not included.** The AMB repository (https://github.com/vectorize-io/agent-memory-benchmark) has no licence file, so
  none of its code or data is included here.
- **What the scripts do.** `verify/rescore_vectorize.py` and the scripts in `data/comparison/scripts-as-run/` download or
  load AMB's files at run time from the pinned commit `20751fa03d8795200a246cf4fc904605cf4a905a`, check their sha256, and
  run them unchanged.
- **Hindsight's results file.** It is referenced by URL and sha256 only. `data/comparison/hindsight-published-results-summary.json`
  records a few numbers derived from it.

## Model outputs
- **Generators.** The answers, plans, notes and memory-pack selections were generated by DeepSeek V4.1 Flash (served by
  Hive) and TypeSafe jev-1.13.0, with embeddings from Voyage AI.
- **Judges.** The judge outputs come from OpenAI gpt-4.1-mini. The comparison scores come from Google Gemini.
- **Why they are included.** They are evaluation records.

## Credentials and personal data
- **Credentials.** No API key, token or credential is included. Every file was scanned for key patterns before packaging.
- **Personal data.** BEAM's conversations are synthetic. The only personal detail is the author's local username, which
  appears in file paths in the run logs and scripts.
