Cost, speed and latency

A memory system has two kinds of latency. Pre-processing builds the memory before any question arrives; in live use, each session is noted when it ends. Query time is what a question costs once its memory exists: retrieval builds the context, then the answer is written.

Check it yourself

In a minute, with Python 3

  1. Clone the repository, or download the proof package above and unzip it.
  2. Run each verifier: 19 checks for BEAM-1M, 9 for LongMemEval-S. They need no network and no keys.
  3. Read CLAIMS.md, then spot-check one question by hand (VERIFY.md, last section).
git clone https://github.com/arnavgupta00/memory-public
cd memory-public && python3 beam-1m/verify/verify.py --deep
python3 longmemeval-s/verify/verify.py

Add --online to check against third parties: the Wayback Machine's copies of GitHub's records, and for LongMemEval the dataset, the evaluator and all 500 judge prompts. To re-judge all 700 answers with BEAM's official evaluator yourself, see VERIFY.md, level L3 (about $2.50 of OpenAI usage).
